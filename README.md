# Portfolio-project
This is my portfolio project As Backend Software Engineer, created for ALX Africa Powered by Holberton INC.

## The Purpose For This Project
	This project is to help people find the best products for their needs in some categories like phones, tablets, pc parts, home equipment and more.

## Target Users
	This project was created for anyone to have the eligibility to purchase products online.

## **Technologies Used:**
	- For the backend I'm using Nest (NestJS) is a framework for building efficient, scalable Node.js server-side applications. It uses progressive JavaScript, is built with and fully supports TypeScript and combines elements of OOP (Object Oriented Programming), FP (Functional Programming), and FRP (Functional Reactive Programming).
	Under the hood, Nest makes use of robust HTTP Server frameworks like Express

	- For the security issues like hashing users passwords and generating web tokens I'm using Bcrypt, passport and JWT.

	- Prisma is a great ORM supports many databases SQL and NoSQL databases, Easy to use and the best functionality I like about it that is generate types for each data model so we can double check the data comes from the user and with DTOs (Data Transfer Object) we made data insertion in the database very strict.

	- For the database for now we're using Postgres SQL database and we're planning to distribute the data between to databases (Postgres and MongoDB) to get the most advantage of using SQL and NoSQl database and to make the process of manipulating.

	- For the frontend now I'm using Flask for generating the HTML for me just because I didn't learn anything about modern Frontend frameworks till now but I'm planning to use in the future NextJS and Tailwind CSS.

	- For the Server that will host this project I'm using Ubuntu server, Nginx and Docker.


## **Project Features**
- Search by (brand, categories, name)
- Get products with discount
- The website is responsive and compatible with mobile

## Finally
In this project I learned a lot I learned how the system designed, what to consider when planning for a project in high scale how the database affects the smoothness of the application when it’s done wrong, how the authentication and authorization work to secure the application, how to write code in structured way to separate every module and link them together in efficient way to maintain high performance and high availability and more.
